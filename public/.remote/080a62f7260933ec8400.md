ブログを書く時などに、 `/Users/ユーザー名/*` 部分を匿名化したい。

# 置換コマンド

```vim
:%s/\(\/Users\/\)\w\+/\1user_name/g
```

# コマンド化

```vim
command! ChangeUsersDirName :%s/\(\/Users\/\)\w\+/\1user_name/g
```

後は `:ChangeUsersDirName` で呼び出すだけ!!!
